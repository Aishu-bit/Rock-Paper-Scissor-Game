# ✊✋✌️ Rock Paper Scissors Game

An interactive and fun **Rock Paper Scissors Game** built using **HTML, CSS, and JavaScript** where the user plays against the computer using clickable images. The game keeps track of scores, displays the winner of each round, and provides a smooth and engaging user experience.

---

## 🎮 Features

✨ User-friendly interface with clickable images  
✨ Play against the computer  
✨ Random computer choice generation  
✨ Real-time score tracking  
✨ Winner announcement after every round  
✨ Attractive UI with responsive design  
✨ Smooth gameplay experience  

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the game
- **CSS3** – Styling and animations
- **JavaScript (ES6)** – Game logic and functionality

---

## 📸 Game Preview

### User vs Computer Gameplay

- Select your move using images:
  - ✊ Rock
  - ✋ Paper
  - ✌️ Scissors

- Computer automatically generates its move

- Result is displayed instantly:
  - You Win 🎉
  - You Lose 😢
  - Draw 🤝

- Scores are updated live after every round

---

## 🧠 How the Logic Works

### Step 1: User Choice

User clicks on one of the three images:

```javascript
rock / paper / scissors

Step 2: Computer Choice

Computer randomly selects one option using:

Math.random()

Step 3: Winner Decision

Conditions are checked using JavaScript logic:

- Rock beats Scissors
- Paper beats Rock
- Scissors beats Paper

Step 4: Score Update

The winner’s score increases and updates on screen instantly.
